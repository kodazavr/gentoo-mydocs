# Графический стек Intel: переход с i915 на Xe

Документ описывает подготовку к переходу с `i915` на `xe` с Iris/Zink и
Vulkan ANV. Перед переключением нужно проверить поддержку конкретного GPU и
иметь рабочий вариант отката. Состояние ASUS B5402 записано в
[системном разделе](../systems/asus-b5402/hardware/graphics.md).

> Примеры Dracut ниже показывают промежуточную конфигурацию с `i915`. Не
> копируй их без проверки PCI ID, версии ядра и поддержки `xe`.

## 1. Драйвер ядра (Xe — цель)

Драйвер собран в виде модуля, что позволяет гибко управлять параметрами загрузки через `modprobe.d` или Dracut.

### Конфигурация ядра

- `CONFIG_DRM_XE=m` — основной модуль включен.
- `CONFIG_DRM_XE_DISPLAY=y` — поддержка вывода изображения (обязательно для ноутбука).
- `CONFIG_DRM_XE_DP_TUNNEL=y` — поддержка DisplayPort через Thunderbolt/USB4 (важно для ASUS ExpertBook).

Загрузка: В целевом варианте модуль `xe` форсируется через Dracut для ранней инициализации видеоподсистемы, что критично для плавного перехода к Wayland-композитору (Niri).

### Пример промежуточной конфигурации Dracut

До перехода конфигурация может выглядеть так:

Файл: `/etc/dracut.conf.d/10-drivers.conf`

```bash
# Драйвер Xe для графики Intel 12-го поколения (отключён до перехода)
#force_drivers+=" xe "

add_drivers+=" i915 "

add_drivers+=" nvme "
```

При переходе на `xe` строку с `force_drivers` нужно раскомментировать, а `add_drivers+=" i915 "` — убрать или закомментировать.
## 2. Mesa и OpenGL/Vulkan

В системе сосуществуют два подхода к рендерингу OpenGL. В `make.conf` указаны:

```makefile
VIDEO_CARDS="intel zink"
```

- **Драйвер по умолчанию (Iris)**: Несмотря на наличие Zink, согласно `/etc/env.d/99mesa`, основным драйвером для OpenGL сейчас установлен:

```bash
MESA_LOADER_DRIVER_OVERRIDE="iris"
```

Это обеспечивает максимальную нативную производительность для Alder Lake.

- **Zink (OpenGL поверх Vulkan)**: Установлен как альтернатива. Позволяет использовать трансляцию вызовов OpenGL в Vulkan, что полезно для отладки или работы с приложениями, требующими специфических расширений, реализованных в Vulkan-драйвере anv.
- **Vulkan**: Используется драйвер anv (Intel Vulkan), который нативно работает с ядерным модулем xe.

## 3. Нюансы для Niri (Wayland)

Использование xe + iris в чистом Wayland-окружении минимизирует задержки ввода (input lag) и исключает проблемы с разрывами кадров (tearing). Благодаря `CONFIG_DRM_XE_ENABLE_SCHEDTIMEOUT_LIMIT=y`, драйвер защищен от необоснованных сбросов (reset) при высоких нагрузках, что повышает общую стабильность системы.
