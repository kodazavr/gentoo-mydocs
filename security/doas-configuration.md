# Настройка doas

`doas` предоставляет компактную конфигурацию повышения привилегий. Записанная
политика ASUS B5402 находится в
[системном разделе](../systems/asus-b5402/security/doas.md).

## Конфигурация

Файл: `/etc/doas.conf`

```conf
# Разрешить пользователю выполнять команды от root с сохранением пароля на время сессии
permit persist :wheel

# Сохранять переменные окружения для конкретного пользователя
permit keepenv <username>

# Разрешить выполнение snapper без ввода пароля (для снапшотов)
permit persist :wheel as root cmd snapper
```

## Основные команды

| Команда | Описание |
|---------|----------|
| `doas <command>` | Выполнить команду от root |
| `doas -s` | Запустить shell от root |
| `doas -u <user> <command>` | Выполнить команду от конкретного пользователя |

## Преимущества doas

- Легковесный и простой
- Меньше зависимостей, чем sudo
- Легче в настройке для базовых задач
